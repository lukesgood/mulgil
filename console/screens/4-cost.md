# 4. 비용 (Cost) — Chisu 모듈

> Phase 3. Sumun O2(비용 귀속)와 같은 시점에 구현.

## 목적
플랫폼이 얼마를 쓰고 있고, 어느 테이블과 어느 호출자가 쓰는지 보여준다.
프로파일에 따라 돈(AWS)이거나 환산액(온프렘)이다. 예산 설정·차단은 하지 않는다 —
호출자 예산은 Sumun, 클라우드 예산은 AWS Budgets.

## 데이터
| 엔드포인트 | 내용 | 산식 (ops/API.md) |
|---|---|---|
| `GET /cost/summary?from&to` | 총액, 일별 추이, 프로파일 구성(저장/스캔·연산/유지보수/고정), 전기간 대비 | 프로파일별 산식 |
| `GET /cost/by-table` | 테이블별 저장 바이트·비용, 스캔 바이트·비용, 유지보수 비용, 레이어 | Athena 로그·CUR·단가표 |
| `GET /cost/by-caller` | 호출자(에이전트/서비스 계정)별 스캔 바이트, 모델 토큰, 추정 비용, 호출 수 | Sumun `GET /usage/export` 집계 (가명화 완료, 행 단위 아님) |
| `GET /metrics/query` | 스캔 바이트 시계열 등 | Prometheus |

## 화면 구성
1. **헤더** — 기간 선택(이달/지난달/30일/사용자 지정), 총액, 전기간 대비, 월말 예측, 통화. sovereign은 "환산액 — 단가표 기준" 라벨.
2. **구성 도넛** — 저장 / 스캔·연산 / 유지보수 / 고정(EKS·노드) / 미귀속.
3. **일별 추이** — 누적 영역 그래프, 구성별.
4. **테이블별 표** — 상위 20, 레이어 필터, 바이트와 금액 병기. 행 클릭 → 테이블 상세.
5. **호출자별 표** — 상위 20, Sumun 호출자명, 호출 수, 스캔 바이트, 토큰, 비용. 행 클릭 → 거버넌스 화면 해당 호출자.
6. **단가표 (sovereign만, operator)** — 노드 월 환산액, TB·월 저장 단가, CPU 시간 단가 입력 폼. 저장 시 전체 재계산.

## 동작
- 읽기 전용. 단가표 입력만 쓰기(`PUT /cost/rate-card`).
- v0 비용 소스는 Athena 쿼리 로그 + 단가표. **CUR 파싱은 v1** — 그때까지 aws 고정비는 "미귀속"이 아니라 "미수집"으로 표시.
- CSV 내보내기(테이블별·호출자별).

## 빈 상태·오류
- CUR 미연결(aws): "Cost and Usage Report 연결 필요" + Terraform 변수 안내. Athena 스캔 비용은 쿼리 로그만으로 표시.
- 단가표 비어 있음(sovereign): 금액 열 숨기고 바이트·CPU 시간만 표시, 상단에 입력 링크.
- Sumun 집계 API 불가: 호출자 표 대신 배너, 나머지는 정상.

## 인수 기준
- [ ] aws-serverless에서 1TB 스캔 쿼리 실행 후 24시간 내 by-table에 $5 전후가 잡힌다.
- [ ] 호출자별 합이 Sumun `GET /usage/export`의 `estimated_cost` 합과 일치한다(같은 소스이므로 오차 0).
- [ ] sovereign에서 단가표 입력 전후로 금액 열이 숨겨지고 나타난다.
- [ ] 고정비는 테이블·호출자에 배분되지 않고 "미귀속"으로 표시된다.
